# RuralBank DataNavigator Demo

基于大模型与 NL2SQL 的银行业智能问数系统交互 Demo。

## Demo 内容

- 自然语言问数、口径识别、多轮追问与专业 SQL 模式
- 经营分析、风险管控、客户营销三类核心业务场景
- 可视化图表、明细下钻、结果导出、分享、收藏与看板
- 指标中心、历史查询与结果可信度说明
- 指标治理、语义知识库、数据模型、权限安全、评测中心、审计监控
- 机构级、岗位级、行列字段级权限及动态脱敏交互演示

> 本项目仅用于产品与技术方案演示，所有机构、客户、指标和查询结果均为模拟数据，不代表任何真实银行经营情况。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建验证：

```bash
npm run build
```

## 技术说明

- Next.js / React / TypeScript
- vinext + Vite
- Cloudflare Worker 兼容构建
- 当前 Demo 使用浏览器端模拟数据，不连接真实数据库或大模型服务

生产化时应将自然语言理解、指标语义层、NL2SQL、安全网关、查询执行、审计和评测服务部署在银行受控环境中，并接入统一身份、数据中台与权限平台。
